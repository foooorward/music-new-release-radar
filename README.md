# 每日新歌雷达

采集各平台公开的音乐新发行数据，按**综合热度分**从高到低排序，产出每日表格与网页看板。

**在线看板：** https://foooorward.github.io/music-new-release-radar/

每一行记录：歌名、歌手、收录平台、所在榜单、最佳名次、发布时间、跨平台数、热度分。

## 看板怎么用

打开上面的链接即可，支持：

- 按平台筛选（网易云 / 酷狗 / Apple）
- 按数据范围筛选，默认「仅平台新歌榜收录」——只看平台新歌榜收录的作品，避开榜单里的经典老歌
- 按发布时间区间筛选
- 关键词搜索歌名 / 歌手
- 点击表头排序，可切换「只看跨平台收录」

## 自己跑一份

```bash
python run.py
```

跑完打开 `output/dashboard.html`（双击即可，无需服务器）。只依赖 Python 3.9+ 标准库，不需要安装任何东西。

| 参数 | 作用 |
| --- | --- |
| `python run.py` | 采集今天的数据并产出报告 |
| `python run.py --date 2026-10-09` | 指定日期（补跑 / 回填） |
| `python run.py --no-enrich` | 跳过歌手信息补充，速度快 3 倍左右 |
| `python run.py --only netease` | 只跑指定数据源 |
| `python run.py --insecure` | 关闭 TLS 证书校验，仅用于排查代理拦截 |

### 产出物

| 文件 | 说明 |
| --- | --- |
| `output/dashboard.html` | 网页看板（自包含单文件，数据内嵌，可离线打开） |
| `output/新歌雷达-新发行-YYYY-MM-DD.csv` | 新发行榜：只含被平台新歌榜收录的作品 |
| `output/新歌雷达-YYYY-MM-DD.csv` | 全量榜单：所有上榜作品按热度分排序 |
| `output/新歌雷达-YYYY-MM-DD.xlsx` | 装了 `openpyxl` 才额外产出 |

两个 CSV 都是 UTF-8 带 BOM，Excel 双击不乱码。

## 热度分怎么算

```
热度分 = 100 × (榜单名次×0.45 + 跨平台覆盖×0.25 + 音乐人热度×0.15 + 榜单爬升×0.15)
```

权重可在 `config.json` 的 `scoring.weights` 里调整。「榜单爬升」需要至少两天的快照做对比，连续运行两天后才会出现有效数值。

## 使用提醒

- 数据来自网易云、酷狗、Apple 各平台的公开接口，**仅供个人研究使用**。
- 请保持每天 1～2 次的采集频率，高频抓取会触发平台风控。
